# 第 3 章　层级视觉 Transformer：Swin 与密集预测

原始 ViT 把整幅图像变成固定分辨率的 token 网格，并在每一层做全局注意力。这个设计适合用 class token 完成分类，却与检测、分割的两个需求发生冲突。第一，密集任务既要高分辨率定位，也要低分辨率语义，通常希望主干提供多个输出步幅；第二，高分辨率输入产生大量 token，全局 $N\times N$ 注意力很快成为计算和显存瓶颈。

Swin Transformer（`liuSwinTransformerHierarchical2021`，L3）分别用层级下采样和局部窗口回应这两个问题。Patch merging 让 token 网格逐阶段缩小、通道增加，形成类似 CNN 的金字塔；窗口注意力只计算局部位置对，使每层成本随图像面积近似线性。窗口又会隔断通信，因此相邻层交替使用常规窗口和移位窗口，让信息逐步跨过边界。

## 3.1 密集预测需要怎样的 backbone 接口

第二册的 FPN 接收多个尺度的特征，例如输出步幅 4、8、16、32。浅层高分辨率特征保留位置，深层低分辨率特征包含更大范围语义。原始 ViT 在全部层中维持同一个 patch 网格，只有深度变化，没有天然的空间金字塔。

假设输入为 $H_0\times W_0$，初始 patch 边长为 4，则第一阶段 token 网格约为

$$
H_1\times W_1
=\frac{H_0}{4}\times\frac{W_0}{4}.
$$

若随后每个阶段把高和宽各减半，四个阶段的输出步幅就是 4、8、16、32。这些特征可以直接接入 FPN、Mask R-CNN 或分割解码器。Swin 的“通用 backbone”含义主要来自这种接口和计算组织，而不是说所有任务共享完全相同的预测头。

## 3.2 Patch merging 怎样完成下采样和通道变换

设某阶段输入为

$$
X\in\mathbb R^{B\times H\times W\times C},
$$

并暂时假设 $H,W$ 为偶数。Patch merging 取每个相邻 $2\times2$ token，把四个 $C$ 维向量沿通道拼接：

$$
X_{\mathrm{cat}}
\in\mathbb R^{B\times(H/2)\times(W/2)\times4C}.
$$

归一化和线性投影再把通道通常变成 $2C$：

$$
X'=X_{\mathrm{cat}}W_m,
\qquad
W_m\in\mathbb R^{4C\times2C}.
$$

所以空间 token 数降为原来的四分之一，通道只增为两倍。总激活元素从 $HWC$ 变为约 $(H/2)(W/2)(2C)=HWC/2$，而单个 token 汇集了更大空间范围。

这个操作与步幅卷积一样会丢失空间分辨率。层级结构提供不同尺度，不代表金字塔无损。若超小目标在初始 patch embedding 或第一次 merging 前已经与背景混合，后续层只能根据上下文推测，不能重建未被保留的独立像素证据。

## 3.3 窗口注意力为什么近似线性

设某层特征网格为 $h\times w$，token 数 $N=hw$，通道维为 $C$。全局注意力的位置对项约为

$$
O((hw)^2C).
$$

把特征划分成不重叠的 $M\times M$ 窗口。每个窗口有 $M^2$ 个 token，窗口数为 $hw/M^2$。一个窗口中的位置对为 $(M^2)^2$，所有窗口合计

$$
\frac{hw}{M^2}(M^2)^2
=hwM^2.
$$

所以注意力位置对计算约为

$$
O(hwM^2C).
$$

当 $M$ 固定时，它对图像面积 $hw$ 近似线性。若 $56\times56$ token 使用 $7\times7$ 窗口，共有 $(56/7)^2=64$ 个窗口；每个窗口只处理 $49\times49$ 的注意力矩阵，而不是整层 $3136\times3136$ 矩阵。

更完整地看，Q/K/V 与输出线性投影还有约 $O(hwC^2)$ 的成本。窗口化主要降低的是位置对项，不会让全部运算消失。FLOPs 接近也不保证实际延迟接近：窗口分区、数据搬移、mask 和大量小矩阵能否被硬件高效实现同样重要。

## 3.4 固定窗口为什么会形成信息孤岛

如果每层永远采用同一组不重叠窗口，窗口 A 中的 token 只能读取 A，窗口 B 中的 token 只能读取 B；堆叠再多层，两组也不会直接交换信息。位于窗口边界两侧、空间上相邻的两个像素会被人为分开。

Swin 在相邻 block 中交替使用 W-MSA 和 SW-MSA。W-MSA 使用常规窗口；SW-MSA 将窗口沿高、宽方向各偏移约 $M/2$。偏移后，上一层属于不同窗口的一些 token 会落入下一层同一窗口，从而建立跨边界通信。

这种通信是逐层扩展的，不是一步全局。一个 token 第一层读取本窗口，下一层可接触邻近窗口的成员，再经过更多层传播到更远处。大建筑、公里级道路或跨整景关系仍可能需要足够深度、额外全局机制或切片间信息交换。

## 3.5 Cyclic shift 为什么还需要 attention mask

直接构造移位后的不规则边界窗口不利于批量计算。高效实现先对特征做 cyclic shift，把超出一侧的 token 循环移到另一侧，然后仍按规则 $M\times M$ 窗口分块。这样可以复用窗口计算内核。

循环移位却在数组中把原图左边和右边、上边和下边暂时拼到一起。这些位置在真实图像中并不相邻。系统因此为移位窗口构造 attention mask，把同一规则窗口中实际来自不连续区域的 token 对设为不可见。mask 是维持真实邻接关系的正确性条件，不只是优化速度的小技巧。

窗口大小还会遇到整除问题。若 $h,w$ 不能被 $M$ 整除，通常需要填充到可分窗尺寸，再用 mask 排除无效 token。下游恢复原图时也要裁掉填充区域，评价不能把它们当作真实像素。

## 3.6 相对位置偏置表达了什么

窗口内两个 token 的相对位移为 $(\Delta x,\Delta y)$。若窗口边长为 $M$，每个方向的位移范围是 $[-(M-1),M-1]$，共有

$$
(2M-1)^2
$$

种二维相对位置。Swin 为不同相对位移学习偏置，并把它加到注意力 logit：

$$
A
=\operatorname{softmax}
\left(\frac{QK^\top}{\sqrt{d_k}}+B+M_{\mathrm{attn}}\right).
$$

$B$ 按 token 对的相对坐标查表，$M_{\mathrm{attn}}$ 是移位或填充 mask。相对偏置告诉模型“另一个 token 在左上、右侧或多远”，不把参数绑定到整幅图的绝对格点，因此较容易适应不同图像分辨率。

但它仍以 token 位移为单位。跨 GSD 时，相同的 $\Delta x=1$ 可能代表 0.3 米，也可能代表 10 米；相对位置机制不会自动理解物理距离。改变窗口大小时，偏置表本身也可能需要插值或重新学习。

## 3.7 Swin 与 CNN 的相似和差别

Swin 重新引入了局部窗口、共享分区规则和逐阶段下采样，因此在接口和归纳偏置上更像卷积主干。区别在于，卷积核权重训练完成后在各位置共享，单次前向不随当前邻域内容改变；窗口注意力的聚合权重由当前 Query 与 Key 计算，同一窗口位置在不同图像上可采用不同通信模式。

这并不允许把 Swin 与 CNN 的实验差异全部归因于“动态注意力”。训练增强、优化器、阶段深度、归一化、激活和下游框架都可能贡献。公平比较必须对齐预训练、参数量或计算量、训练时长和数据配方。ConvNeXt 等研究进一步说明，现代训练与宏观结构可以显著增强卷积网络；架构名称不是单一因果变量。

## 3.8 遥感大图中的四个尺度问题

第一是初始 token 的物理支持域。若初始 patch 边长为 $P$ 像素、GSD 为 $g$ 米/像素，一个初始 token 约覆盖 $Pg$ 米边长。每次 Patch merging 使 token 的名义步幅再翻倍。报告 Swin 配置时，应把像素 patch、各阶段输出步幅和目标物理尺寸一起列出。

第二是窗口覆盖。某阶段步幅为 $s$ 像素、窗口边长为 $M$ token，则窗口在输入上的跨度约为 $Ms$ 像素，在地面上约为

$$
L_{\mathrm{window}}\approx Msg.
$$

这个量帮助判断单层能否同时看到道路两侧、完整建筑或密集目标群。它只是名义覆盖，真实有效信息还受遮挡、特征质量和层间传播影响。

第三是切片与窗口的双重边界。超大遥感影像仍常需切片；一个长对象可能先被 patch 边界分割，再被窗口边界限制，还可能在切片边缘截断。重叠切片能缓解整景边界问题，但不会消除主干内部的局部通信限制。

第四是方向和模态。方形窗口不具备旋转等变性，任意方向目标仍需数据增强或专门结构。扩展 patch embedding 的输入通道可以让 Swin 接收多光谱，却不会自动编码波段物理含义、传感器响应和缺失模态。

## 3.9 怎样诊断层级窗口模型

若小目标性能差，首先检查初始 patch 和早期 merging，而不是直接扩大深层窗口；若大对象被切碎，检查窗口跨度、跨窗传播层数和切片重叠；若理论 FLOPs 下降但速度不升，检查窗口操作、批量、内核和内存访问；若跨 GSD 性能变化，检查每阶段和窗口对应的地面尺度。

密集预测实验应同时保存各阶段特征或响应可视化，并在同一 FPN 或 decoder 下与基线比较。只有下游框架固定，才能较可靠地区分主干层级结构的贡献。

## 论文对照与原文核查点

Swin（`liuSwinTransformerHierarchical2021`，L3）是本章主读。应核查全局 MSA 与窗口 MSA 的完整复杂度；Patch merging 前后的形状；W-MSA 与 SW-MSA 的交替方式、cyclic shift 和 mask；相对位置与绝对位置的消融；分类、检测和分割实验是否使用相同预训练与模型规模；并区分理论 FLOPs、吞吐和端到端下游速度。

## 练习与答案要点

1. $56\times56$ token 使用 $7\times7$ 窗口，共有多少窗口？答：$(56/7)^2=64$。
2. 为什么只堆叠固定不重叠窗口会形成信息孤岛？答：分区永远不变时，不同窗口中的 token 从不进入同一个注意力集合。
3. cyclic shift 后为什么必须使用 mask？答：循环移动会把原图两端在数组中拼接，mask 要阻止这些本不相邻位置产生虚假注意。
4. 输入 GSD 为 0.5 米/像素，某阶段步幅为 8 像素，窗口为 $7\times7$ token，窗口地面边长约多少？答：$7\times8\times0.5=28$ 米。
5. Swin 是否天然解决细长道路的长程连通？答：不。移位窗口使信息逐层跨界，但公里级关系仍需多层传播，且早期下采样可能损失细道路。
