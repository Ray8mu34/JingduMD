# 高亮、找回与备份（0.8.3）

## 日常使用

1. 鼠标选中正文，点击弹出的黄色、绿色、蓝色或粉色即可保存高亮。右键选区或 `Ctrl+Shift+M`（Mac 为 `⌘+⇧+M`）也可以打开色板。
2. 单击已高亮的文字，直接改色或点垃圾桶删除。选中同一段文字再选颜色不会增加重复高亮。正文中的链接和按钮仍按原来的用途工作。
3. 删除后点击底部“撤销删除”。关闭提示或重启后，也能从“更多 → 标注管理与备份 → 回收站”恢复。
4. 右侧“大纲 → 高亮”提供当前文档摘录、颜色与跳转；同一面板可进入管理窗口。键盘快捷键为 `Ctrl+Shift+H`（Mac 为 `⌘+⇧+H`）。

## 文件改名或搬家

新高亮会记录文档身份和内容指纹。打开文件夹及文件树更新后，应用会在当前文件夹内扫描 Markdown：旧路径确实不存在、文件内容一致且匹配唯一时，自动迁移高亮记录。仅复制文件、存在多个相同副本、文件不可读取或内容已改变时，不会自动猜测。

如果没有自动找回：

1. 在“更多 → 标注管理与备份”中打开新文件夹，点击“扫描找回”。
2. 进入“待关联”，点击左边旧文章，右边仍能查看摘录。
3. 点击“选择对应文件”，选择当前打开文件夹内的那篇 Markdown，检查路径后点击“确认关联”。

手动关联会保留原摘录和目标文章已有的标注。文章内容被修改后，应用根据引用文本、上下文和标题重新定位；无法唯一定位的摘录保留为待恢复，不会贴到不确定的位置。

旧版本的记录只有路径和摘录。升级后，只要原文件还在，应用能补充指纹；如果升级前原文件已经移走，就需要手动关联。数据库和备份都已删除的标注无法凭空恢复；高亮摘录也不能还原整篇原文。

扫描只针对打开的文件夹，不遍历整台电脑；跳过符号链接、隐藏/缓存目录以及超过 64 MiB 的文件。内容指纹会统一 CRLF/LF 换行。文件外部编辑后，重新阅读可刷新指纹；未被观察到的编辑再搬家可能需要手动关联。

## 换电脑与保留备份

- 点击“导出备份”，保存 JSON。备份包含所有目录的摘录、上下文、颜色、定位信息和回收站；请把 Markdown 原文件另行备份。
- 新电脑上先“导入备份”，再打开原文件所在的新文件夹并“扫描找回”。Windows 和 Mac 使用同一种备份格式。
- 重复导入同一备份会跳过已有标注，不会覆盖当前颜色或让已删除记录重新出现。需要恢复删除的标注时使用回收站。
- 备份上限为 20 MiB / 50000 条标注；超过上限会明确报错。备份是明文，保存或分享时应把摘录视为原文的一部分。
- 回收站不自动过期。确认不再需要后可按文档永久删除其中的标注，空记录会一并清理。文件暂时离线或无法读取不会触发删除。

这些功能共用 Windows / macOS 的前端与 Rust 实现。资料目录不产生旁车文件，高亮仍由静读和导出的备份管理，不会自动写进 Markdown 或同步到其他阅读器。
