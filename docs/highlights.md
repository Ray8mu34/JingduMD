# 文件内高亮、迁移与备份

## 阅读时做标记

选中文字后点击黄色、绿色、蓝色或粉色。右键选区或 `Ctrl+Shift+M`（Mac 为 `⌘+⇧+M`）也能打开色板。高亮写入 Markdown，复制、改名或移动文件时自动一起携带。只读文件会明确报错。

```markdown
==🟡黄色== ==🟢绿色== ==🔵蓝色== ==🟣粉色==
==🟡整句黄色，其中 ==🔵这里蓝色==，随后恢复黄色。==
```

四色使用静读原有色值和透明度；粉色用紫色圆点记录，在 Obsidian 中可能呈紫色。普通 `==文字==` 也能读取，使用黄色。红、橙圆点读取时分别对应粉色、黄色，重新保存统一为本应用四色。

颜色圆点打开一层，单独 `==` 关闭最近打开的一层。内层颜色优先，删除内层后恢复外层；重复涂抹不累计加深。无颜色标记按普通成对高亮解析，未配对标记保留为文字。静读的嵌套规则属于扩展，不能保证其他 Markdown 软件或 Obsidian 原生按同样方式显示嵌套。

同一段落内的连续高亮保留一对标记，可完整包含粗体、斜体和链接；例如 `==🟡正文 **粗体** 与 [链接](url)==`。旧的同色片段仅在中间没有未高亮正文、且不影响其他高亮层时合并。交叉选区、跨段落或表格单元格、以及只选中部分格式文字并越过其边界时才拆分。拆分后的片段可分别点击、改色和删除。选区可以经过公式、代码等内容：自动跳过无法映射的部分，保存选中的正文高亮，不拒绝整段。起点或终点在公式内时也仅保留选中的正文；纯公式选区不产生正文高亮。公式、代码、原始 HTML、无法映射到源码的 wikilink 和含转义/实体等无法准确映射的文字本身暂不写入高亮；不会猜测修改位置。

右侧“大纲 → 高亮”列出当前文件的标注，可跳转、改色、删除。快捷键 `Ctrl+Shift+H`（Mac 为 `⌘+⇧+H`）。旧数据库标注仍可显示和找回；给旧标注改色会先备份并将这一条写入文件。

## 删除与恢复

文件内高亮删除后，点击底部“撤销删除”恢复。撤销使用内存中的操作记录，要求删除后文章未发生其他修改，避免覆盖新内容。源码编辑沿用编辑器的撤销历史。删除旧数据库标注仍进入旧标注回收站。

日常保存不再逐次复制完整文件。恢复点集中保存于应用数据目录的 `recovery.sqlite3`：同一文件至少间隔 5 分钟，仅在内容变化时记录，保留 7 天且每篇最多 3 个；全局数据库上限 64 MiB。超过 8 MiB 的文件跳过恢复点，不影响正常保存。启动及保存时自动清理，恢复记录故障不会阻止普通保存。打开、阅读和无变化的源码保存不会新增记录。

- Windows：`%APPDATA%\com.jingreader.app\recovery.sqlite3`
- macOS：`~/Library/Application Support/com.jingreader.app/recovery.sqlite3`

恢复点包含完整原文字节，不参与日常渲染或撤销。UTF-8 BOM 和 UTF-16 编码保留；GBK 文件加入颜色圆点时转换为 UTF-8。换行和正文文字不改写。

保存前校验文件内容，并在提交前再次校验原字节，再用同目录临时文件替换原文件。检测到外部编辑或替换失败时不覆盖原文。应用自己的高亮写入在多个窗口间串行执行；其他编辑器仍可能在最后一次校验与替换之间写入。

## 迁移旧数据库高亮

打开对应资料目录，在“更多 → 标注管理与备份”点击“迁移当前目录旧高亮”。

1. 开始前备份完整数据库至 `highlight-backups/migration-…/annotations.sqlite3`，包含 SQLite WAL 中已提交的数据。
2. 对每篇文章按摘录和上下文查找唯一位置，按嵌套/交叉规则生成文件标记。
3. 每篇写入前另行备份原文字节。成功写入后，相关旧记录才进入回收站。
4. 无法定位、重复摘录不明确、缺失、不可读或不可写的文章不猜测迁移，原记录继续保留。完成后显示成功数、跳过数、失败原因及备份路径。

可以重试失败的迁移。已归档的旧记录不再参与；恢复过的旧记录再次迁移时，对已有相同颜色和范围的标记尽量去重。文件替换后若数据库归档失败，原文件可能已经带标记，错误会给出备份路径，旧记录依然可恢复。

旧文件搬家后，先“扫描找回”；内容相同、旧路径消失且匹配唯一时自动关联，否则在“待关联”选择对应文章。扫描仅针对当前目录，不扫描整台电脑。

## Windows 文件保存

Windows 保存时采用同目录临时文件替换。若原文件被索引、预览等程序短暂占用（32、33、1175），自动进行有上限的重试；每次重试都重新检查磁盘原文与只读属性。持续占用时提示关闭占用窗口后重试，保留原文及备份；等待期间发生外部修改则取消保存。

## 旧标注导入导出

“导出备份”生成旧数据库标注 JSON，包含摘录、上下文、颜色和回收站；新文件内高亮需连同 Markdown 文件一起备份。新电脑可导入旧 JSON，再打开资料目录扫描找回并迁移。备份上限为 20 MiB / 50000 条标注。

标注管理窗口管理旧数据库记录；文件内高亮在当前文章右侧面板管理。设置中的高亮数量及清除操作也仅针对旧数据库记录。
