# 阅读中的源码小修

打开已有、有稳定路径的 Markdown 后，点击顶部“源码”进入编辑。输入完整原文，不经过阅读用公式、图片或高亮预处理。源码查找定位真实文本及语法；编辑使用原生 textarea，无自动配对、补全、实时预览或自动保存。Ctrl+S 手动保存。原生输入、剪切粘贴和图片引用共享本次编辑的撤销重做历史，保存后仍可撤销。退出源码、切换文件或标签、重启后不保留该历史，也不持久化未保存草稿。

草稿仅保存在当前编辑会话。阅读器、打印及高亮均使用已保存内容；源码模式暂不提供打印和标注管理。离开编辑、打开文件或文件夹、切换或关闭活动标签、关闭窗口时，若有修改，先显示应用内“保存并继续 / 放弃修改 / 继续编辑”确认。只有第一个待决离开请求能获准，后续请求不会共用其批准。处理保存或插图期间禁止丢弃及导航。真正的页面卸载仅在存在草稿或操作尚未完成时使用 beforeunload；正常桌面关闭通过 Tauri close-requested 事件复用应用内确认。

保存基于打开时的原始 `doc.content` 和原始字节 SHA-256 revision，保存前再次核对磁盘。外部修改（包括只改变编码/BOM）、只读、文件删除及 canonical 路径变化都会使保存失败并保留输入，不提供强制覆盖。失败后可继续编辑、复制所需源码，或放弃修改并返回阅读最新磁盘版本。文件监听在编辑时只核对基线，不载入覆盖草稿；忙碌期间略过的事件在操作完成后再次核对。自身保存产生的相同 revision 事件不触发外部更新提示。

变更保存复用原字节备份（应用数据目录 `highlight-backups`）、同目录排他临时文件、sync、写前再次检查与原子替换；备份失败不写原文。没有内容变化时不写盘、不备份。高亮原接口“只能修改标记、不能修改正文”的保护保持独立有效。

## 基础语法着色

源码模式区分 Markdown 标题、粗体/斜体/删除线、行内代码、围栏代码块、链接/图片、列表和引用标记的颜色，随应用外观切换。粗体、斜体和删除线使用紫色强调，夜间为浅紫色，避免仅靠接近正文的深浅变化区分。它是保守的基础着色：代码块整体着色，不分析代码块内部编程语言，也不改变源码、补全或自动配对。以文本片段绘制，原始 HTML 不会执行。

原生 textarea 持续负责输入、选区、撤销和保存。只读着色镜像逐字符同步，排除屏幕阅读器访问，水平及垂直滚动与原生输入一致；中文输入法组字和系统强制配色期间显示原生文字，保留系统下划线和选区绘制。超过 50 万 UTF-16 字符的文档、超过 8000 字符的单行及行内标记过于密集的行保留普通文字，限制实时分析成本。

## 编码和换行

读取沿用 UTF-8 BOM、UTF-16 BOM、UTF-8、GBK fallback。修改后保留 UTF-8 BOM 或 UTF-16 的 BOM 和字节序；无 BOM 的 GBK 文档修改后写为 UTF-8。不能保证任意编码或无效字节逐字节往返；原始字节可从写前备份恢复。

textarea 内部使用 LF。完全无改动或撤销回原文时不写盘，原有字节和混合换行保持原样。发生变更后，原文统一使用 CRLF 或 CR 时保留该换行；原为 LF、无换行或混合换行时写为 LF。

## 插入图片

“插入图片”每次选择一张本地图片，复制到当前 Markdown 同级 `images` 目录，再在当前选择处插入 `![](images/文件名)`。支持 png、jpg/jpeg、gif、webp、svg、bmp、ico、avif，拒绝空文件及超过 50MB 的文件。使用安全文件名和递增后缀，排他创建，不覆盖已有图片；拒绝已有 images 符号链接或 Windows junction。不提供截图粘贴、拖放、上传或下载。

复制失败不插入引用；原生插入失败时只尝试清理本次未使用、且未被外部改动的副本。引用成功插入后，即使随后确认通信失败，也保留图片。撤销图片引用、放弃文字修改或退出应用均不会自动删除已复制的图片；可自行整理 images。除显式插图外，编辑不会创建其他用户资料文件。

## 验证入口

- `pnpm test`：换行、私有草稿、保存基线、并发离开、失败保留及原有阅读测试。
- `cargo test --lib`：原字节备份、编码、无变化、冲突、只读、删除、备份失败、临时文件清理和图片避重名。
- `node scripts/qa-source-editor.mjs`：Edge 中原生输入、粘贴、撤销重做、手动保存、查找、插图失败、冲突、IME 事件、离开确认、标签、文件夹与窗口关闭模拟；390/760/1280px 和夜间截图。
- `node scripts/qa-source-syntax.mjs`：390/760/1280px 的文本无损同步、输入及撤销、查找、滚动像素对齐、夜间外观、窗口调整、组字回退与强制配色。
- `node scripts/qa-native-source-editor.mjs`：使用独立 QA 应用标识，在真实 Windows WebView2 和临时资料目录验证磁盘保存、备份、外部变更、只读、删除、插图及关闭事件；仅替代操作系统文件选择器的返回值，保存与图片命令均执行真实 Rust。需先按脚本顶部命令构建独立测试应用，不安装或替换正式应用。未验证 macOS 原生撤销和实际中文输入法候选窗口。
