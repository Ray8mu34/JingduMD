# 0.8 阅读界面改善计划

依据：`v0.8-ui-reading-review.md` 与用户提供的顶部栏截图。

## 实施顺序

- [x] 1. 统一顶部栏：字体、图标、按钮尺寸、打开菜单、选中与悬停状态、窗口控制；直接提供专注阅读入口。
- [x] 2. 保证可读空间：提前切换窄窗侧栏，调整表格内容列与日期列的最小宽度。
- [x] 3. 精修阅读排版：大纲对比度、深层标题、中西文标题搭配、短代码块密度。
- [x] 4. 完善辅助 UI：设置实时样张与模式说明、参数说明、长文件名、位置恢复提示和空白状态。

## 设计约束

保留暖纸、白纸与夜读主题；UI 使用独立且统一的无衬线字体，不随正文书页字体变化。保持现有快捷键、只读文档与非侵入式偏好设置。宽表使用局部滚动，不拆成卡片；保留作者内容和列对齐。暂不改变已安装版本，先完成源码与可审阅的预览。

## 已实现的行为

- 顶部栏使用 13px 无衬线 UI 字体、18px 线性图标及 32px 按钮；移除打开按钮独立外框与 Aa 衬线字样；统一悬停、展开与选中状态，保留 Windows 关闭按钮的红色悬停提示。
- 1080px 以下采用侧栏浮层，避免双侧栏将正文压窄；可直接进入专注阅读，再通过文件／大纲按钮退出并打开对应面板。
- 普通 Markdown 表格按列内容设置日期、短字段、说明列宽。日期和短字段不拆行，长说明列至少 11em，单元格顶端对齐，保留水平滚动；有合并单元格的作者表格不进行自动分类。打印时解除这些屏幕最小宽度。
- 大纲为 14px，普通条目加深，深层缩进封顶；文件名最多显示两行。
- 阅读模式默认西文标题优先 Source Serif／Noto Serif／Cambria，避免 Georgia 数字与英文过重的观感；用户明确指定的字体继续优先。H5/H6 增强字重与间距。
- 1–3 行代码收紧留白；单行样例由约百像素降至约 72px。
- 1280px 及以上，快速阅读设置停靠右侧，并临时让出大纲区域；窄窗保留弹层。设置提供实时混排样张、模式解释、约每行字数、参数单位说明及恢复范围说明，详细面板也可撤销调整。
- 恢复中途阅读位置后显示可关闭的提示，8 秒后自动消失，可一键返回文首；空白状态根据文件列表是否展开选择提示。
- 修正综合样例 20 列表格分隔行缺失的一列。
