# JingReader 0.9.1

修复本地图片引用上级目录时无法显示的问题。

## 修复

- 直接打开 Markdown 文件或其所在子目录时，`../`、`../../` 引用当前浏览根目录之外的共享图片现在可正常加载。例如 `course/01-solar-system/slides.md` 中的 `../../assets/01/relations.png`。
- 图片路径仍相对 Markdown 文件位置解析，兼容中文、空格和 URL 编码路径，Markdown 图片及 HTML `<img>` 均适用。
- 图片读取带上当前标签页的文档上下文，保留文档访问边界、图片类型检查和 50 MiB 大小上限；文件树、正文链接和搜索仍使用原有目录边界。
- 本次修复不涉及 Pandoc 的标题及图片属性语法。
- 兼容新版 Rust 的严格检查，远程图片并发限制保持为四个请求。

## 下载

- Windows x64：推荐 `JingReader_0.9.1_x64-setup.exe`，另提供 MSI 和 `JingReader-Portable-0.9.1.exe`。
- Apple Silicon Mac：选择 `JingReader_0.9.1_aarch64.dmg`。
- Intel Mac：选择 `JingReader_0.9.1_x64.dmg`。
- Mac 最低系统版本为 macOS 14.2，同时提供 App ZIP。
- SHA-256 校验值见 `SHA256SUMS.txt`。

## 验证

本机通过 95 项前端测试、34 项 Rust 测试、格式与 Clippy 检查，以及 Windows WebView2 原生渲染回归。原生回归覆盖只打开 Markdown 文件时加载两级上跳图片、中文及空格路径、HTML 图片和同目录图片。

三平台发布构建另执行现有自动化检查；Mac 包验证架构及 codesign 完整性。Mac 使用 ad-hoc 签名，未做 Developer ID 签名或公证；Windows 包未做代码签名。
