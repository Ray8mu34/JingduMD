# JingReader 0.8.2

本次发布将 0.8.1 的最新阅读界面与功能带到 macOS，并补齐 Mac 系统集成。

- Windows 与 macOS 共用统一工具栏、专注阅读、窄窗浮层侧栏、排版实时预览与停靠设置，以及最新表格、标题和代码排版。
- Mac 增加中文原生菜单，支持打开文件/文件夹、对照窗口、文内查找、目录搜索、阅读设置与 PDF 导出；菜单操作作用于活动阅读窗口。
- Mac 正文和标题使用 Core Text 提供的真实常规、粗体、斜体和粗斜体字体名称。
- 修复 Mac 打印面板尚未结束就恢复文章折叠状态的问题；打印结束或取消后恢复阅读状态。
- 修正 Mac 快捷键提示及阻塞安装包构建的 Rust 检查问题。

## 下载选择

- Apple Silicon Mac（M 系列芯片）：`JingReader_0.8.2_aarch64.dmg`。
- Intel Mac：`JingReader_0.8.2_x64.dmg`。
- Mac 另提供对应架构的 `.app.zip`，解压后将应用拖入“应用程序”。
- Windows 普通安装：`JingReader_0.8.2_x64-setup.exe`。
- Windows MSI：`JingReader_0.8.2_x64_zh-CN.msi`。
- Windows 免安装：`JingReader-Portable-0.8.2.exe`。
- 所有安装包的校验值见 `SHA256SUMS.txt`；各平台构建清单随包提供。

macOS 要求 14.2 或更新版本。Mac 安装包使用临时签名，未进行 Apple Developer ID 签名和公证；首次打开可能被系统拦截。Windows 安装包未进行 Authenticode 签名。

保留现有设置、阅读位置和高亮，不修改 Markdown 资料。Mac GUI 尚未进行人工实机验收。
