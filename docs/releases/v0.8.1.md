# JingReader 0.8.1

本次更新统一阅读界面，并改善窄窗口与技术文档的排版。

- 顶部栏统一字体、线性图标、按钮尺寸与交互状态，新增专注阅读入口。
- 窄窗侧栏提前切换为浮层，避免正文被两侧导航挤压。
- 表格日期和短字段不拆行，长说明列保留合理宽度，宽表继续支持局部横向滚动。
- 提高大纲可读性，改善深层标题与中西文标题搭配，压缩短代码块的多余留白。
- 阅读设置增加实时预览；宽窗口支持停靠布局，并补充排版模式和参数说明。
- 文件名支持两行展示，恢复阅读位置时可以一键返回文首。
- 修正综合测试样例的 20 列表格格式。

## Windows 下载

- 首次安装或普通个人使用：`JingReader_0.8.1_x64-setup.exe`。
- 已使用 MSI 安装或需要全机部署：`JingReader_0.8.1_x64_zh-CN.msi`。
- 免安装运行：`JingReader-Portable-0.8.1.exe`。
- 校验信息：`SHA256SUMS.txt` 和 `release-manifest.json`。

安装包未进行 Authenticode 签名。升级保留应用设置及阅读记录，不修改 Markdown 资料。

## 验证

前端 66 项单元测试、构建、工具栏与设置交互、阅读位置恢复、多主题布局与打印检查通过。新增 UI 回归覆盖 760、933、1080、1380、1600px 窗口、表格末列可达、设置停靠、短代码高度及阅读恢复提示。

本次提供 Windows x64 安装包；不提供未经实机验证的 macOS 安装包。
