# R6 连续排版校样记录

基线：`5b5b55b` 后的 R1–R5；样张由 `pnpm qa:continuous-proof` 固定生成。校样运行于 Windows 上的 Edge 浏览器完整 App 测试入口，视口 1100×900，默认字号 18.5 px、栏宽 760 px。这里的截图和计算值是浏览器证据；桌面 WebView、其他缩放与平台仍须分别验收。

## 同内容黑白校样

黑白校样先屏蔽四套外观的页面色与代码语法色，以同一内容比较 `reading` 和 `study`。覆盖中文长文、英语长文、混合教材及 README 的开头、正文中段、深层标题、公式、代码与宽表格。截图和每一处的计算值存于 `qa-artifacts/r6/`，其中 `metrics.json` 记录实际正文/标题字号、行高、段距、栏宽和页面横向溢出。

| 观察处 | 阅读 | 研读 | 处理 |
| --- | --- | --- | --- |
| 长文正文 | 18.5 px 字号、34.225 px 行高、16.28 px 段距 | 18.5 px 字号、32.93 px 行高、12.21 px 段距 | 保留舒展与紧凑的差别，不改变相同内容能力和栏宽 |
| H1–H3 | 衬线标题，层级温和 | 克制的无衬线标题，章节更清楚 | 保留既有字体角色与字号比例 |
| H5–H6 | 原 H6 为 17.76 px，低于正文 | 同样低于正文，连续深层标题显得拥挤 | H6 调至 1em，即默认 18.5 px；H5/H6 顶部间距略增 |
| 粗斜体、行内代码 | 与正文一起阅读，代码小一档但字形清楚 | 强调与章节同用真实粗体 face，代码不打断推理 | 当前光学大小保留用户可调的 `codeScale`，没有强行加大所有代码 |
| 解释—公式—续文 | 公式没有内部纵向滚动，前后文字仍属同一推理 | 同一内容使用略紧的块间距 | 保留 R4 校准值，避免再用主题色区分数学 |
| 长代码与宽表 | 块本身可横向滚动，页面宽度没有溢出 | 行文与块边界更紧凑 | 保留独立宽块，不扩大整篇栏宽 |

黑白校样例：[中文阅读深层标题](../qa-artifacts/r6/mono-chinese-longform-reading-deep.png)、[中文研读深层标题](../qa-artifacts/r6/mono-chinese-longform-study-deep.png)、[混合教材阅读公式](../qa-artifacts/r6/mono-typography-proof-reading-math.png)、[混合教材研读公式](../qa-artifacts/r6/mono-typography-proof-study-math.png)。22 处记录的页面横向溢出均为 0 px；长代码和宽表在自己的容器内处理宽度。

## 四种外观

完成黑白对照后，在同一篇混合教材、同一位置分别查看 warm、white、night、nord × 两套 profile，共 8 张截图。没有为外观重新设置字重、栏宽或块间距。`qa:style-contract` 另以真实 DOM 节点、选区与几何证明单独换色不会重建整篇正文。

## Windows 原生窗口复核

使用单独的 `com.jingreader.qa` 构建，不影响正在运行的旧版实例。真实 WebView2 窗口打开 `typography-proof.md`：短公式无内部纵向滚动条；本机枚举返回 326 种字体，搜索 `Arial` 后为 4 / 326，清空搜索可浏览完整列表。搜索阶段正文未改变；明确选择 Noto Serif SC 中文正文、Noto Sans SC 中文标题和 Arial 西文标题后，混合标题的中文字形与拉丁字形分别改变。

关闭并重启此 QA 构建后，再从文件列表打开样张，自定义标题字形仍在。系统打印预览中可见同一组自定义标题字形；取消打印返回原来的正文。本次没有把打印作业交给实体打印机，也没有生成原生 PDF，因此 PDF 的嵌入字体仍以 R5 的 Edge PDF 产物检查为证据。

在真实窗口把 `typography-proof.md` 滚至末尾，再点此前未打开的 `chinese-longform.md`，新文档从 H1 和首段出现；回点原文则恢复到末尾。此路径补充了完整 App 自动化的 R1 检查。当前 Windows 的 `AppliedDPI` 注册表值为 144；未切换系统显示缩放，也未验证 macOS。

## 剩余人工门槛

- 作者确认两套排版在真实窗口里的阅读感受和最终数值。
- 在真实桌面窗口做一次 15–20 分钟连续阅读，记录打断阅读的实际动作；截图和自动测试不能替代此项。
- 在目标缩放和跨平台环境核对字体回退、公式与打印输出；当前记录不声明像素级一致。
